# PWC-Net 光流估计网络架构解析

## 1. 概述

PWC-Net (Pyramidal Warping Cost volume Network) 是一种用于光流估计的深度学习方法。该网络采用**多尺度金字塔结构**，结合**特征提取器 (Extractor)**、**解码器 (Decoder)** 和**精炼器 (Refiner)** 三个核心模块，自底向上逐层细化光流估计。

**输入**: 两张 RGB 图像 (shape: [B, 3, H, W])
**输出**: 光流场 (shape: [B, 2, H, W])

## 3. Extractor (特征提取器) 详细结构

Extractor 是一个6阶段的特征金字塔，每个阶段包含3个卷积层 + LeakyReLU，采用 **Conv → ReLU → Conv → ReLU → Conv → ReLU** 的模式。

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Extractor 特征提取器                               │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入: [B, 3, H, W]                                                 │
│       │                                                             │
│       ▼                                                             │
│  ┌─────────────────────────────────────────────────────────┐        │
│  │  netOne (Stage 1)                                       │        │
│  │  Conv2d(3→16, k=3, s=2, p=1) → LeakyReLU(0.1)          │        │
│  │  Conv2d(16→16, k=3, s=1, p=1) → LeakyReLU(0.1)         │        │
│  │  Conv2d(16→16, k=3, s=1, p=1) → LeakyReLU(0.1)         │        │
│  │  输出: [B, 16, H/2, W/2]                                │        │
│  └──────────────────────┬──────────────────────────────────┘        │

## 4. 核心操作详解

### 4.1 Correlation (相关性体积计算)

```
┌─────────────────────────────────────────────────────────────────────┐
│                 torch_correlation(tenOne, tenTwo)                    │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入: tenOne [B, C, H, W], tenTwo [B, C, H, W]                    │
│                                                                     │
│  步骤:                                                               │
│  1. tenTwo 进行 padding: pad=4, 形状变为 [B, C, H+8, W+8]          │
│  2. 初始化 corr = zeros([B, 81, H, W])                             │
│  3. 遍历位移范围 dy∈[-4,4], dx∈[-4,4] (共81个位移):                 │
│     ┌─────────────────────────────────────────┐                    │
│     │  for dy in -4..4:                       │                    │
│     │    for dx in -4..4:                     │                    │
│     │      shifted = tenTwo 裁剪 [H,W] 区域    │                    │
│     │      corr[:, idx] = mean(tenOne *       │                    │
│     │                         shifted, dim=1) │                    │
│     │      idx += 1                           │                    │
│     └─────────────────────────────────────────┘                    │
│                                                                     │
│  输出: corr [B, 81, H, W]  (81通道相关性图)                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 4.2 Backwarp (反向战争/图像扭曲)

```
┌─────────────────────────────────────────────────────────────────────┐
│                     backwarp(tenInput, tenFlow)                      │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入: tenInput [B, C, H, W], tenFlow [B, 2, H, W]                 │
│                                                                     │
│  步骤:                                                               │
│  1. 构建归一化网格 grid [B, H, W, 2] 范围[-1, 1]                    │
│  2. 光流缩放:                                                        │
│     flow_x = tenFlow[:, 0] * (2.0 / (W-1))                         │
│     flow_y = tenFlow[:, 1] * (2.0 / (H-1))                         │
│  3. 网格偏移: grid = grid + flow                                    │
│  4. 双线性采样: F.grid_sample(tenInput, grid)                       │
│                                                                     │
│  输出: warped_feature [B, C, H, W]                                  │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 5. Decoder (解码器) 详细结构

Decoder 有5个层级 (Level 2~6)，每个层级是一个独立的 Decoder 实例。

### 5.1 Decoder 输入通道配置

```
intPrevious[Level+1] = [None, None, 81+32+2+2, 81+64+2+2, 81+96+2+2, 81+128+2+2, 81, None]
intCurrent [Level+1] = [None, None, 81+32+2+2, 81+64+2+2, 81+96+2+2, 81+128+2+2, 81, None]

Level 6: intCurrent = 81  (仅correlation体积，无上一级输入)
Level 5: intCurrent = 81+128+2+2 = 213
Level 4: intCurrent = 81+96+2+2  = 181
Level 3: intCurrent = 81+64+2+2  = 149
Level 2: intCurrent = 81+32+2+2  = 117
```

## 6. Refiner (精炼器) 详细结构

Refiner 使用**空洞卷积 (Dilated Convolution)** 逐步扩大感受野，对光流进行精细化修正。

```
┌─────────────────────────────────────────────────────────────────────┐
│                      Refiner 精炼器                                  │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │

## 7. 完整前向传播流程

```
┌─────────────────────────────────────────────────────────────────────┐
│                    前向传播 Forward() 流程                            │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  输入: tenOne [B,3,H,W], tenTwo [B,3,H,W]                          │
│                                                                     │
│  Step 1: 特征提取                                                    │
│  ─────────────────────────────────────────────────────────────────  │
│  tenOne = Extractor(tenOne)  →  [f1,f2,f3,f4,f5,f6]               │
│  tenTwo = Extractor(tenTwo)  →  [f1,f2,f3,f4,f5,f6]               │
│                                                                     │
│  Step 2: 自底向上逐层解码 (金字塔从粗到细)                             │
│  ─────────────────────────────────────────────────────────────────  │
│                                                                     │
│  objEstimate = Decoder6(tenOne[-1], tenTwo[-1], None)              │
│  # 输入: feat6 [B,196,H/64,W/64]                                   │
│  # 输出: flow [B,2,H/64,W/64], feat [B,...,H/64,W/64]              │
│                                                                     │
│  objEstimate = Decoder5(tenOne[-2], tenTwo[-2], objEstimate)       │
│  # 输入: feat5 [B,128,H/32,W/32] + 上一级上采样                     │
│  # 输出: flow [B,2,H/32,W/32], feat [B,...,H/32,W/32]              │
│                                                                     │
│  objEstimate = Decoder4(tenOne[-3], tenTwo[-3], objEstimate)       │
│  # 输入: feat4 [B,96,H/16,W/16] + 上一级上采样                      │
│  # 输出: flow [B,2,H/16,W/16], feat [B,...,H/16,W/16]              │
│                                                                     │
│  objEstimate = Decoder3(tenOne[-4], tenTwo[-4], objEstimate)       │
│  # 输入: feat3 [B,64,H/8,W/8] + 上一级上采样                        │
│  # 输出: flow [B,2,H/8,W/8], feat [B,...,H/8,W/8]                  │
│                                                                     │
│  objEstimate = Decoder2(tenOne[-5], tenTwo[-5], objEstimate)       │
│  # 输入: feat2 [B,32,H/4,W/4] + 上一级上采样                        │
│  # 输出: flow [B,2,H/4,W/4], feat [B,565,H/4,W/4]                  │
│                                                                     │
│  Step 3: 光流精炼                                                    │
│  ─────────────────────────────────────────────────────────────────  │
│  refine_flow = Refiner(objEstimate['tenFeat])                      │
│  # 输入: feat [B,565,H/4,W/4]                                      │
│  # 输出: refine_flow [B,2,H/4,W/4]                                 │
│                                                                     │
│  Step 4: 融合与缩放                                                  │
│  ─────────────────────────────────────────────────────────────────  │
│  flow = (objEstimate['tenFlow'] + refine_flow) * 20.0              │
│  # 逐元素相加后缩放20倍                                              │
│  # 输出: flow [B,2,H/4,W/4]                                        │
│                                                                     │
│  Step 5: 上采样到输入分辨率                                           │
│  ─────────────────────────────────────────────────────────────────  │
│  flow = Interpolate(flow, size=(H, W), mode='bilinear')            │
│  flow[:,0] *= W / (W/4)  # 水平方向缩放补偿                          │
│  flow[:,1] *= H / (H/4)  # 垂直方向缩放补偿                          │
│  # 最终输出: flow [B,2,H,W]                                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

## 8. 网络参数量与特征维度总结

### 8.1 整体数据流

```
输入图像 ──H×W──▶ Extractor ──H/64×W/64──▶ Decoder6
                                                    │
                                              上采样▼
                                              Decoder5  ──H/32×W/32
                                                    │
                                              上采样▼
                                              Decoder4  ──H/16×W/16
                                                    │
                                              上采样▼
                                              Decoder3  ──H/8×W/8
                                                    │
                                              上采样▼
                                              Decoder2  ──H/4×W/4
                                                    │
                                              输入Refiner
                                                    │
                                              ┌───▼───┐
                                              │ flow  │
                                              │ +ref  │
                                              │ ×20   │
                                              └───┬───┘
                                                  │
                                            双线性上采样
                                                  │
                                                  ▼
                                            输出光流 H×W
```

### 8.2 激活函数统一说明

- 全部使用 **LeakyReLU(negative_slope=0.1)**
- 除了最后一个输出卷积层 (netSix in Decoder, last conv in Refiner) 不使用激活函数

### 8.3 关键设计特点

| 特点 | 说明 |
|------|------|
| 多尺度金字塔 | 6级特征提取，5级解码，从粗到细 |
| Cost Volume | 81通道相关性图，搜索范围±4像素 |
| 反向战争 | 利用上一级光流对特征进行对齐 |
| 残差式拼接 | 每层Decoder内部采用特征拼接 (类似U-Net) |
| 空洞卷积精炼 | Refiner使用d=1,2,4,8,16扩大感受野 |
| 光流缩放因子 | 20.0倍最终缩放，保证光流值范围正确 |
